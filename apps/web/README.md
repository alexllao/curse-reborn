# Futura web de Curse Reborn

Paquete reservado `@curse-reborn/web` para la presentación del port, descargas e integración futura del juego WebAssembly. Todavía no contiene un sitio, servidor, diseño ni una compilación para navegador.

Compartirá los recursos propios de `@curse-reborn/assets`. La lógica del juego permanece en `../juego`; no se duplicará en JavaScript. El marco web se elegirá cuando se trabaje en esta aplicación.
